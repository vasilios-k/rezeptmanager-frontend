# Rezeptmanager – Frontend

Vue-Anwendung zum Anzeigen einer Rezeptsammlung.
Das Projekt wird als Einzelprojekt umgesetzt.

## Technologien
- Vue 3 mit TypeScript
- Vue Router
- Vite
- ESLint und Prettier

## Stand: Milestone 2
- Eigene Unterkomponente RecipeList.vue
- Darstellung der Beispielrezepte mit v-for
- Getrennte Datentypen, Beispieldaten und Mengenformatierung
- Deutsche Einheiten und Zahlenformatierung
- Responsive Rezeptübersicht mit aufklappbarer Zubereitung

Die Backend-Anbindung folgt mit Milestone 3.

## Lokal starten
1. Abhängigkeiten installieren: `npm install`
2. Entwicklungsserver starten: `npm run dev`

## Code prüfen
- Formatieren: `npm run format`
- Codeanalyse: `npm run lint`
- Produktionsbuild: `npm run build`
